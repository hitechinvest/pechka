# Гонки на печках в Дубае

Простая браузерная 3D-игра: русские печки на колёсах гоняют по кольцевой трассе
среди небоскрёбов и песка. На перекрёстках работают светофоры — проехал на
красный, значит дисквалификация.

## Как запустить

Открыть `index.html` в браузере — двойным щелчком по файлу или так:

```
python3 -m http.server 8000   # затем http://localhost:8000
```

Ничего устанавливать не нужно: three.js лежит рядом в `vendor/`, картинки и звуки
генерируются на ходу (canvas + WebAudio), интернет не требуется.

Есть и версия одним файлом — `build/pechki-dubai.html`. Её можно скинуть куда
угодно и открыть двойным щелчком, всё внутри. Пересобирается так:

```
node build.js
```

## Правила

- Перед стартом выбирается от 1 до 7 живых игроков. Всего на трассе 8 печек,
  за остальных играет компьютер.
- Газ у каждого игрока — своя клавиша: **1**…**7** (у первого ещё **↑** и **Пробел**).
  Держишь — печка разгоняется, отпускаешь — тормозит. Рулить не нужно, печка
  сама держится своей полосы.
- На трассе шесть перекрёстков со светофорами. Они переключаются сами:
  зелёный → жёлтый → красный → зелёный.
- **Проехал стоп-линию на красный — дисквалификация**: печка глохнет и вылетает
  из гонки. На жёлтый ехать ещё можно.
- Когда **загорается зелёный**, звучит **гудок паровоза** — сигнал, что можно жать.
- Компьютерные соперники разные: осторожные тормозят заранее, лихачи иногда
  влетают на красный и снимаются сами.
- Побеждает тот, кто первым проедет выбранное число кругов и не будет снят.

## Управление

| Клавиша | Действие |
|---|---|
| `1`…`7` | газ игроков 1–7 |
| `↑`, `Пробел` | газ игрока 1 |
| `C` | переключить камеру на другую печку |
| `V` | вид: за печкой / дальний план / сверху |
| `M` | звук вкл/выкл |
| `R` | вернуться в меню с экрана результатов |

На телефоне и планшете вместо клавиш работают кнопки «Игрок N» внизу экрана.

## Что внутри

```
index.html        разметка, стили, HUD, меню
src/game.js       гонка: физика, светофоры, ИИ, камера, интерфейс
src/world.js      трасса, город, печки, дым, текстуры на canvas
src/audio.js      синтез звука на WebAudio (гудок, гул печки, зуммер)
vendor/three.min.js  three.js r134 (MIT)
```

Полезные мелочи для отладки — в консоли браузера:
`__dbg()` показывает состояние гонки, `__renderInfo()` — число draw call'ов.
